# 墨排 · MOPAI

本地 Markdown 微信公众号排版工作台。连接文章目录，选择主题，微调细节，再将富文本排版复制到公众号编辑器。

## 开始使用

需要 **Node.js 20.19+**（或 Node.js 22.12+）。

```powershell
npm install
npm run dev
```

打开 <http://127.0.0.1:5173>。本地 API 服务使用 3001 端口，网页开发服务使用 5173 端口。

发布版本可这样运行：

```powershell
npm run build
npm start
```

此时直接打开 <http://127.0.0.1:3001>。服务只监听本机地址，无需微信账号或 API 密钥。

## 使用流程

1. 将 `.md` 文章放入项目的 `articles` 目录，或点击左上角文件夹卡片，连接其他本地目录。会递归读取子目录，并自动同步新增、修改或移走的文件。
2. 在文章库打开文章，切换「编辑 / 双栏 / 预览」。可以新建、导入或拖入 Markdown 文件。
3. 选择右侧主题，或在「样式微调」调整字体、字号、行距、段距、主题色、标题、作者日期和文末外链。主题与细节按文章自动保存。
4. 点击「复制到公众号」，在微信公众号后台图文编辑器的**正文区域**粘贴。公众号的标题栏需要单独填写；如不需要正文中的重复标题，可关闭「显示文章标题」。
5. 在微信手机预览中确认最终效果，尤其是图片、表格和外链。

桌面端左侧工作空间默认展开，可通过侧栏或顶部的收起按钮隐藏，再从顶部展开；右侧排版主题默认收起，点击工具栏的「排版主题」即可展开或收起。双栏模式下，编辑器与预览按滚动进度双向联动。小屏幕沿用侧边抽屉，避免占用正文空间。

内置「山间来信」「Claude」「编程教程」「字里行间」「日落橘子海」「深蓝来稿」「晚风与诗」「旧日书页」「玫瑰手记」「青竹留白」10 套主题。每套主题有独立的字体、标题和引用样式。

点击主题卡片底部的「设为默认」，即可为新文章和未单独设置排版的文章指定默认主题。内置主题和自定义主题均可选择，设置保存在本地，刷新、重启或切换文章目录后继续生效。已单独保存排版的文章沿用自己的设置；移除当前默认的自定义主题后，恢复为「山间来信」。

「Claude」参考 [Claude 官网](https://claude.com/) 的配色：暖白 `#FAF9F5`、陶土色 `#D97757`、深灰 `#141413`，配合柔和的暖灰背景与衬线标题。正文中的强调和代码高亮适当加深，兼顾品牌色的温度与阅读对比度。可打开 [Claude 主题排版示例](articles/Claude%20主题排版示例.md) 预览；文章背景、引用、表格和暖灰代码块均包含在生成的富文本排版中。

「编程教程」适合技术文章：蓝色步骤标题、深色代码块、清晰的语法高亮、代码语言标识、行内代码、提示引用和参数表格。代码字号会随正文字号调整，长代码行自动换行，复制到公众号时保留这些样式。可以打开 [编程教程排版示例](articles/编程教程排版示例.md)，再选择此主题体验。

## 从公众号文章提取主题

点击「从链接提取主题」，粘贴 `https://mp.weixin.qq.com/s/...` 或带参数的 `/s?__biz=...` 文章链接。墨排通过本地服务读取文章，分析正文和内嵌 CSS，提取主要颜色、字号、行距、标题、强调、引用等样式。提取后可以命名、预览并保存为自己的主题。

微信可能返回验证页面、限制自动访问，或文章已经失效。这时可以先在浏览器打开文章，按 `Ctrl + S` 保存为「网页，全部」，再在「导入网页」中选择 `.html` / `.htm` 文件；也支持直接粘贴 HTML 源码。

主题提取是**可识别排版样式的近似复用**，不复制原文内容和装饰图片，不包含动画、复杂布局和外部 CSS 文件。链接提取允许下载最多 16 MB 的网页，自动移除脚本、嵌入页面和注释，再在 4 MB 的解析范围内识别正文样式；直接导入的 HTML 文件仍限 4 MB。已使用真实公众号文章链接验证提取流程；自动化测试覆盖 HTML 提取、大网页精简、请求限制和微信验证页面的错误处理。

## Markdown 与图片

支持标题、加粗、斜体、引用、有序/无序列表、嵌套列表、表格、链接、图片和带语法高亮的代码块。可选的 YAML 元数据示例：

```markdown
---
title: 把生活调成自己喜欢的频道
author: 作者名称
date: 2026.09.15
category: 生活观察
summary: 可选的一句话简介
---

# 把生活调成自己喜欢的频道

在这里开始正文。
```

图片可以使用 HTTPS 地址，或相对于文章的路径，例如 `![图片说明](./images/photo.jpg)`。复制文章和导出 HTML 时，本地位图会转换为 PNG 并嵌入图片数据，避免粘贴内容依赖本机地址。若公众号过滤了图片，可从「导出」菜单单独复制封面 PNG，或下载后上传。远程图片可能受来源网站的防盗链限制。

复制内容同时包含 `text/html` 与 `text/plain`，排版样式全部写在 HTML 元素上。浏览器不支持富文本剪贴板时，会尝试选区复制，也可以使用「导出 → 导出排版 HTML」。微信编辑器可能进一步过滤字体、外链或个别样式，最终以公众号手机预览为准。

## 根据文章生成封面

点击文章顶部的「生成封面」，展开「接口配置」即可设置协议、请求地址、API 密钥、模型、图片比例／尺寸和超时时间。可只保存配置；点击「生成并插入」才请求生成一张图片。

- **协议**支持 Images、Responses 和 Chat。Images 调用 `/images/generations`；Responses 直连原生 `/responses`，使用 `image_generation` 工具，需要选择支持该工具的调用模型；Chat 直连 `/chat/completions`，需要渠道支持图片输出扩展。不会将 Responses 转成 Chat，也不会自动切换协议重试。默认使用 Images 和 `gpt-image-2`。
- 常见地址会**自动识别类型**：域名根地址、以 `/v1` 等版本号结尾的地址视为 **Base URL**，追加所选协议的路径；以 `/images/generations`、`/responses`、`/chat/completions` 结尾的**完整请求地址**原样使用，不重复追加。不会自行添加 `/v1`；OpenAI 官方接口的 Base URL 可填写 `https://api.openai.com/v1`。其他自定义路径可手动选择地址类型。切换协议时，已识别的标准完整路径会同步更新，自定义路径保留。
- **获取模型列表**使用正在填写的地址和密钥请求同一渠道的 `/models`，不会先保存配置。获取成功后从下拉列表选择模型；不支持模型列表的渠道可勾选「手动填写模型」，或展开「自定义模型列表地址」。列表中没有当前模型时仍保留当前选择。列表反映渠道提供的模型，不保证每个模型都支持当前协议或具有出图权限。
- 只在接口配置中设置一次**图片比例／尺寸**：公众号封面 **2.35:1（940×400）**、**1:1（1024×1024）**、**16:9（1024×576）**、**9:16（576×1024）**、**4:3（1024×768）**、**3:4（768×1024）**，或选择「自动」使用渠道默认尺寸并保留原始比例。新配置默认 2.35:1；已有配置未指定比例时保留原始图片。
- 同一个比例设置决定构图要求、请求参数与最终 PNG 尺寸。Images 对 GPT Image 2 自动选择满足 16 倍数和最低像素数要求的画布（例如公众号封面请求 1280×544、保存 940×400），GPT Image 1 系列使用其支持的横／竖／方形画布，其他模型按所选尺寸请求；受渠道尺寸限制时可选择「自动」。Responses 图像工具使用自动画布并在提示词中指定构图；Chat 使用渠道扩展 `modalities` 和 `image_config.aspect_ratio`。保存时按所选尺寸等比缩放、必要时居中裁切，不拉伸。生成后检查主体位置，下载 PNG 并在公众号后台选择为列表封面。
- Images 兼容 `data[0].url` 和 `data[0].b64_json`，可配置返回格式；Responses 读取图像工具结果；Chat 读取图片内容块或明确的 Markdown 图片。仅返回文字会提示未返回图片。
- **画面提示词**支持保存多个常用预设。选择已有提示词后可编辑名称和内容，点击「保存提示词」更新；点击「新增提示词」创建另一套，下次打开会恢复上次选择。保存独立于接口配置，不需要 API 密钥，也不会触发图片生成。修改后请先保存或取消，再切换预设；未保存的内容仅用于本次生成，关闭窗口后不保留。最多保存 50 个预设，名称最长 60 字符、内容最长 2,000 字符。
- 生成时将所选提示词与当前编辑草稿的标题、摘要和正文结合；长文保留开头与结尾，正文最多取 12,000 字符。文章内容会发送给所配置的图片服务。
- 临时图片立即下载，用 Sharp 实际转换成 sRGB PNG，保存为文章所在目录中的 `cover-<请求标识>.png`，Markdown 使用相对路径。图片位于正文开头，保留 YAML 元数据。重新生成后会替换开头的旧封面引用，旧图片文件保留。
- 同一请求重试沿用 `X-Request-Id`。本地记录已返回的图片，下载失败后可直接继续下载；服务端重启后也可恢复。生成接口是否避免重复扣费，取决于渠道对这个请求头的支持。不要在不确定上次结果时反复点击「调整后重新生成」。
- 错误提示区分请求服务、读取响应、下载、转换和本地保存，生成记录中保留脱敏的阶段与错误码。若返回“当前密钥所属分组未开通图片生成”，需联系渠道开通或更换密钥；切换模型不能绕过这项权限。
- 复制文章时嵌入 PNG 数据；「复制封面图片」则写入 `image/png` 剪贴板，可单独粘贴。微信公众号最终是否接受富文本内嵌图片由其编辑器决定，下载 PNG 后上传是备用路径。

配置及密钥保存在已被 Git 忽略的 `.mopai/image-settings.json`，提示词预设及上次选择保存在 `.mopai/image-prompts.json`，生成记录保存在 `.mopai/image-jobs/`。密钥不会通过查询配置接口回传浏览器。留空保留同源渠道已有密钥；更换地址域名需要填写新密钥，也可勾选清除。每张输入图片上限 20 MB、4,000 万像素；输出最大边 2048，复制时本地图片总大小上限 30 MB。

## 文件与数据

- 编辑停止约 0.9 秒后自动写回原 Markdown 文件；`Ctrl / ⌘ + S` 可立即保存。
- 目录和主题通过实时变更通知同步：文章变更只刷新目录，主题变更只刷新主题，连续通知会合并。实时连接或文件监听异常时，才在页面可见期间每 15 秒检查一次；恢复连接、切回窗口或手动同步时会补做检查。等待封面生成不会额外轮询目录和主题。
- 检测到外部修改冲突时停止覆盖，保留编辑区草稿，可下载草稿后重新载入。
- 当前目录、文章设置和自定义主题保存在 `.mopai/state.json`，不会写进 Markdown 正文。
- 收藏的主题与最近打开的文章保存在浏览器本地。
- 单篇文章最大 2 MB，导入网页最大 4 MB。目录最多扫描 2,000 篇文章、12 层子目录；隐藏目录、常见依赖目录及符号链接不会被扫描。
- 目录边界、符号链接、跨站请求与远程提取重定向都有检查。远程提取只允许微信公众号的 HTTPS 文章地址。

首次运行前，可通过环境变量指定默认目录：

```powershell
$env:ARTICLES_DIR = 'D:\MyArticles'
npm run dev
```

如果已经在界面中选择过目录，保存的选择优先。之后可以继续从界面切换。

```powershell
npm test
npm run typecheck
npm run build
```
