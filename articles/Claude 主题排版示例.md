# 让好想法，<br>慢慢长成好文字

一个好想法，不必一开始就完美。先把它放在纸上，再给它一点时间、一点耐心，和足够呼吸的空间。

> 不必急着写得漂亮，
> 先把心里的话说明白。

## 01 / 从一个具体的问题开始

面对空白的一页，可以先问自己：**我最想让读者带走什么？**

也许是一个有用的方法，一个值得记住的故事，或者一个新的观察角度。找到这件事，文字就有了方向。

不用一次写出所有答案。先认真表达一个想法，就已经是很好的开始。

## 02 / 给内容，也给读者留白

留白让文字有层次，也让阅读更从容。把长段落拆开，把重要的观点放在合适的位置，读者便能跟上你的思路。

- 一段话，围绕一个清楚的意思展开。
- 一个标题，告诉读者接下来会读到什么。
- 一次强调，留给真正值得停留的句子。

| 写作阶段 | 可以做的小事 |
| --- | --- |
| 收集 | 记下一个问题或一个具体的画面 |
| 表达 | 用自己的话把事情说清楚 |
| 打磨 | 删除重复的话，补上必要的例子 |

### 温度，来自具体的细节

与其说「这是一段美好的时光」，不如写写窗边的光、杯子里的茶，以及那句让你会心一笑的话。

**让读者看见，也让读者感受到。**

## 03 / 技术内容，也可以有温度

写技术文章时，先说明要解决的问题，再给出简洁的例子。像 `remember()` 这样的函数名，也可以成为理解的入口。

```javascript
// 把今天的一个小想法，认真记下来。
function remember(idea) {
  return `今天值得记住的事：${idea}`;
}

console.log(remember('把一件小事讲清楚'));
```

> **写作小提示**：代码之外，别忘了说明它为什么有用。清楚的解释，能让一个例子变得更容易理解。

好文字，不必拥挤。
让每一句话，都有自己的位置。
