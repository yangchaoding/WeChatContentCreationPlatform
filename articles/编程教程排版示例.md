# 用 JavaScript 写一个待办清单

用一个可以直接运行的小例子，把数据结构、函数和错误处理连起来。准备好 Node.js，跟着下面的步骤试一试。

## 01 / 先让代码跑起来

新建 `todo.js` 文件，写入这段代码：

```javascript
const todos = [
  { id: 1, title: '读完这篇教程', done: false },
];

function completeTodo(id) {
  const todo = todos.find(item => item.id === id);

  if (!todo) {
    throw new Error(`找不到任务：${id}`);
  }

  todo.done = true;
  return todo;
}

console.log(completeTodo(1));
```

在这个文件所在的目录打开终端，执行：

```bash
node todo.js
```

输出类似下面这样，`done: true` 表示任务已经完成：

```text
{ id: 1, title: '读完这篇教程', done: true }
```

> **提示**：`todo.js` 保存代码，终端负责运行命令。不要把 `node todo.js` 写进 JavaScript 文件里。

## 02 / 理解每个字段

| 字段 | 类型 | 作用 |
| --- | --- | --- |
| `id` | `number` | 用来查找任务的唯一编号 |
| `title` | `string` | 任务的文字描述 |
| `done` | `boolean` | `true` 表示已完成 |

### 为什么修改后原数组也会变化？

`find()` 返回数组中那个对象的引用。因此，执行 `todo.done = true` 时，修改的也是 `todos` 中保存的任务。

记住这三个步骤，就能读懂这个函数：

1. 用 `find()` 找到对应的任务。
2. 找不到时，用 `throw` 明确报告错误。
3. 找到后更新状态，并返回任务。

## 03 / 把错误也处理好

在同一个 `todo.js` 文件末尾追加下面这段代码，试着完成一个不存在的任务：

```javascript
try {
  completeTodo(99);
} catch (error) {
  console.error('操作失败：', error.message);
}
```

再次运行文件，会先输出已完成的任务，再看到错误提示：

```text
操作失败： 找不到任务：99
```

> **排查思路**：检查任务编号是否存在，以及传入的是数字 `1` 还是字符串 `'1'`。这里使用严格相等比较，两者不会被视为相同的编号。

## 04 / 动手做一点扩展

- 新增一条编号为 `2` 的任务，再调用 `completeTodo(2)`。
- 编写 `addTodo(title)`，为新任务生成不重复的编号。
- 用 `todos.filter(todo => !todo.done)` 找到尚未完成的任务。
